# TombakNet Audit Remediation Report

## Scope and evidence

This report covers only findings in `CQAI_QuantumWGAN_TombakNet_AuditReport.pdf`.
It does not claim completion of FR-6 or FR-8, and it does not treat a synthetic or
newly trained benchmark-only model as the registered production classifier.

Implementation was checked with the focused audit suite, static load-path scans,
Python compilation, and the repository test discovery command.  A production
latency result is intentionally not reported because this checkout has no
compatible registered serving classifier/transform pair.

## Finding status

| Finding | Status | Remediation and verification |
|---|---|---|
| SEC-01 unsafe joblib/pickle loading | PASS (code boundary) | Every production `joblib.load` is behind SHA-256 and fitting-version checks in `cqai/lineage/artifacts.py`. Tests prove a missing/mismatched digest prevents the deserializer call. The trusted manifest must still be protected or signed by deployment controls. |
| SEC-02 NumPy pickle-enabled feature names | PASS | Selected feature names and NSL-KDD string arrays load with `allow_pickle=False`; regression scan/test added. |
| SEC-03 recorded hashes not enforced | PASS (registered local artifacts) | `artifacts/artifact_manifest.json` registers current artifacts and loaders verify identity before executable deserialization. |
| SEC-04 dependency/artifact incompatibility | PASS (fail-closed); rebuild pending | Exact dependency lock added and fitting versions are required at load time. Existing sklearn 1.9.0 artifacts are rejected by the local sklearn 1.8.0 runtime. They must be rebuilt or run in the locked environment before serving. |
| SEC-05 optional serving transform / malformed benign score | PASS | A registered transformer is mandatory. Empty, oversized, non-finite, negative-sentinel, malformed-transform, and invalid classifier outputs fail closed. |
| SEC-07 unknown categorical values | PASS | Transform bundle rejects categories outside fitted vocabularies instead of mapping them silently to an all-zero block. |
| SEC-08 unbounded request batch | PASS | Serving has a configurable positive maximum batch size, default 1024, enforced before transformation. |
| PERF-01 duplicate forest traversal | PASS | Live scoring calls `predict_proba` once and derives labels from `classes_`; `predict` is not called. Equivalence and call-count tests pass. |
| FR-7 p99 <= 50 ms | NOT VERIFIED | Benchmark implementation is complete, preserves raw measurements, and asserts on whole-request p99. It has not been executed because compatible registered serving artifacts and a registered real-flow fixture are absent. **BENCHMARK NOT EXECUTED; no SLA claim is made.** |
| QML-01 over-strict chunk equality | PASS | Exact array equality was replaced by `assert_allclose` with `rtol=1e-12`, `atol=1e-12`. The formerly failing chunking test and the complete suite pass. |
| QML-02 XGBoost/OpenMP SIGSEGV risk | PASS | XGBoost defaults to one worker and CI fixes `OMP_NUM_THREADS=1`. The complete Torch/PennyLane/XGBoost suite ran to completion without a segfault. |
| Tracked Python bytecode | PASS | Tracked `.pyc` files were removed; ignore rules already cover generated bytecode. |

## Serving path

The only live path is:

```text
raw flow DataFrame
  -> registered TransformBundle.transform
  -> registered classical classifier.predict_proba (one traversal)
  -> class and probability output
```

Artifact loading, fitting, training, SMOTE/ADASYN, WGAN/QWGAN generation,
PennyLane/QNode execution, and result serialization are outside this path.

## Required completion run

To close the remaining empirical checks without weakening the controls:

1. Create a clean environment from `requirements-lock.txt`.
2. Rebuild/register the transform bundle and classical classifier in that exact
   environment, recording their SHA-256 values and fitting versions.
3. Supply a deterministic real-flow fixture matching the registered raw schema.
4. Run `scripts/benchmark_live_latency.py` with batches 1, 16, 64, 256, and 1024,
   20 warm-ups, 500 measured requests, and the 50 ms threshold.
5. Retain `results/fr7/raw_latency.csv`, `latency_benchmark.csv`, and
   `latency_summary.json`; report PASS only if every supported batch meets the
   whole-request p99 threshold.

No FR-1/FR-2 transform was refitted or rewritten by this remediation.
